# 4. 基础设施工具

当前页面语言：简体中文。每个条目都包含简短的特点说明。

| 名称与特点 |
| --- |
| [OpenAI API](./OpenAI%20API.zh-CN.md) - 以编程方式接入 OpenAI 模型与智能体能力 |
| [Gemini API](./Gemini%20API.zh-CN.md) - 把 Google 多模态模型接入自己的应用 |
| [DeepSeek API](./DeepSeek%20API.zh-CN.md) - 通过官方 API 使用 DeepSeek 推理与编程模型 |
| [腾讯混元 API](./Tencent%20Hunyuan%20API.zh-CN.md) - 把腾讯混元模型接入企业应用 |
| [Moonshot API（Kimi）](./Moonshot%20API.zh-CN.md) - Kimi 官方 API，用于长上下文应用 |
| [MiniMax API](./MiniMax%20API.zh-CN.md) - 同一家提供商接入文本、语音、图像、视频与音乐生成 |
| [OpenRouter](./OpenRouter.zh-CN.md) - 一个 API 接入多家模型，支持路由与故障切换 |
| [Replicate](./Replicate.zh-CN.md) - 不用自己管服务器，通过 API 运行和部署社区模型 |
| [Together AI](./Together%20AI.zh-CN.md) - 为可下载模型提供生产推理与部署服务 |
| [GroqCloud](./GroqCloud.zh-CN.md) - 用 Groq 专用硬件提供低延迟模型推理 |
| [硅基流动 SiliconCloud](./SiliconCloud.zh-CN.md) - 一个 API 用多家模型，不用自己搭推理服务器 |
| [Exa AI](./Exa%20AI.zh-CN.md) - 为智能体与开发者返回网页内容的搜索 API |
| [Hugging Face](./Hugging%20Face.zh-CN.md) - 发现模型权重、数据集与可运行的社区演示 |
| [Amazon Bedrock](./Amazon%20Bedrock.zh-CN.md) - 在 AWS 上用多家模型，统一管理权限与安全 |
| [Azure AI Foundry](./Azure%20AI%20Foundry.zh-CN.md) - 在 Azure 上构建、评估与部署 AI 应用 |
| [阿里云百炼](./Bailian.zh-CN.md) - 阿里云模型接入与企业 AI 应用平台 |
| [千帆大模型平台](./Qianfan.zh-CN.md) - 百度模型服务与企业智能体云平台 |
| [Ollama](./Ollama.zh-CN.md) - 下载模型，用简洁命令行在本地运行与提供服务 |
| [LM Studio](./LM%20Studio.zh-CN.md) - 桌面上运行本地模型，也可提供本地 API |
| [PyTorch](./PyTorch.zh-CN.md) - 开源张量与深度学习框架，支持 GPU 训练 |
| [DeepSpeed](./DeepSpeed.zh-CN.md) - 优化显存与计算开销，扩展大模型训练规模 |
| [Lightning](./Lightning.zh-CN.md) - 组织 PyTorch 训练流程，扩展到多设备 |
